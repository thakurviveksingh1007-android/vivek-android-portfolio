# Vivek Singh — Android Developer Portfolio

An interactive, responsive portfolio showcasing my Android development work, skills, and experience.

**Live:** [https://thakurviveksingh1007-android.github.io/portfolio/](https://thakurviveksingh1007-android.github.io/vivek-android-portfolio/)

## Highlights

- Animated hero with a working command terminal
- Blueprint-style scroll HUD and section tracking
- Interactive "Blueprint to Reality" playground
- Six project cards with live phone UI previews
- Dark and light theme toggle
- Command palette for quick navigation
- Responsive layout with reduced-motion support

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Inline SVG icons

No build step or framework is required.
